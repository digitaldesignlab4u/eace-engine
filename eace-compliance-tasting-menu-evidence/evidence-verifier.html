EACE.AI — EVIDENCE VERIFIER

Offline verification tool for Evidence Mode records (grade: local or attested). This is a separate tool from the existing completion-receipt decoder — receipts and evidence objects are different artifact types with different trust guarantees; do not conflate their results.

Leave blank if you only need to verify Grade 1 (Local Evidence) records, or if you haven't deployed org attestation yet. See keygen.html to generate an organisation keypair.

This tool performs cryptographic and structural checks only — it does not confirm the named person's real-world identity, and a Grade 1 (Local Evidence) verdict does not mean an organisation attested to this record. Read every check's note, not just the pass/fail badge. Evidence Mode records are a stronger artifact than the product's completion receipt, but "stronger" is not "absolute" — see README.md for the full trust model.
