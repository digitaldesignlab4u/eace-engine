EACE.AI — ORGANISATION EVIDENCE KEYPAIR GENERATOR

Generates the ECDSA P-256 keypair an organisation uses to co-sign Grade 2 (Attested Evidence) records. Runs entirely in this browser tab — the keypair is generated locally and never sent anywhere by this page.

Run this ONCE, on a machine HR/IT actually trusts, then close the tab. This page does not save anything — if you navigate away before copying both keys out, they are gone and you generate a new pair. The PRIVATE key below is the organisation's entire signing authority for Grade 2 evidence: anyone who has it can attest records on the organisation's behalf. Store it like any other organisational secret (a password manager, an HSM if you have one, or at minimum an encrypted, access-controlled file) — never commit it to source control, and never put it anywhere a browser or web server can serve it to the public. This product has no key-rotation or revocation mechanism built in; if this key is compromised, that is a manual incident-response problem for your organisation to handle, the same as any other leaked signing key.
